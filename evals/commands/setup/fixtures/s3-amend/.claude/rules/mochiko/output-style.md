# Writing style

- Documents here are written `full` by default — dense, articles droppable, fragments
  fine. The **Writing style** line in `CLAUDE.md`'s Governance section is the authority
  whenever the two differ.
- Never compress: IDs, identifiers, paths, commands, contract clauses, numeric targets and
  error strings — verbatim.
- Stop compressing wherever it would leave a requirement, criterion or constraint
  ambiguous. A human signs these off, so plain English beats terse every time the two pull
  apart.
- Invoice examples name the sample tenant "Wren Studio", the same one the fixtures use.

# Cadence

Cadence keeps a distributed team's daily standup asynchronous. Each person answers three
prompts during their own morning, and the team reads one digest instead of attending a
meeting.

## Status

Nothing is built yet. This repository was initialized this week and holds only these
notes — no source, no dependencies, no configuration.

## Who it is for

Small engineering teams spread across more than three time zones, where a synchronous
standup costs somebody their evening.

## Intended shape

A web app with a morning email digest. Two engineers working on it part time. The first
pilot is one internal team of six people; if it holds, other teams follow.

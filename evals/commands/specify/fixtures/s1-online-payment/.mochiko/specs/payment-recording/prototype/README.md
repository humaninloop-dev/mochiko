# Prototype — payment recording and reminders

Clickable low-fi rendering of the Screens & Flows manifest in `../spec.md`.

- Serve: `bun run --bun serve .` from this directory, then open the printed URL.
- No bun: open `index.html` directly in a browser; every link is relative.

Screens: `screens/scr-001-record-payment.html`, `screens/scr-002-invoice-status.html`,
`screens/scr-003-reminder-schedule.html`. Flows and data are binding; pixels are not.

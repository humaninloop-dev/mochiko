# Operating docs <!-- GI-009 -->

- `BACKLOG.md` holds open items only; a closed item moves to
  `.mochiko/archive/backlog-trail.md` as one DONE line with a pointer.
- `ROADMAP.md` stays one screen: Now ≤ 5 · Next ≤ 7 · Later ≤ 10.
- A ruled decision gets one `DECISIONS.md` row; its rationale lives in a session record or
  under `.mochiko/decisions/`.

Invariants and the ritual that closes work: `.mochiko/memory/knowledge-management.md`.

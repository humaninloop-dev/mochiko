# Adopt the knowledge-management module

- **Status:** ruled
- **Date:** 2026-06-18
- **Context:** Three thinking sessions and a growing list of "we decided this over lunch"
  items with nowhere to live. The governance amend run offered the operating-docs module.
- **Decision:** Adopt the core whole — sessions index, open-only backlog with a trail, a
  one-screen roadmap, a thin decisions index. Decline `CHANGELOG.md` and `RUNBOOK.md`.
- **Rationale:** Two maintainers cannot carry decisions in chat history; the module's
  landing ritual makes closing an item the same move as deciding it.
- **Alternatives considered:** a single `NOTES.md` (rejected — it grows without bound);
  GitHub issues only (rejected — decisions and rationale do not fit an issue's lifecycle).

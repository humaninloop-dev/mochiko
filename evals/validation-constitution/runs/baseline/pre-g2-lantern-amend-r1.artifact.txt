## Findings requiring fix (blocking)

**1. GI-011 (layer-rules) has no primary home — `.claude/rules/mochiko/layers.md` does not exist.**
Both the region (`CLAUDE.md` line "Layer rules — see `.claude/rules/mochiko/layers.md`") and the
ledger's GI-011 Three-Part entry name this file as the principle's home and the location of the
domain-dependency registry block seeded with `pydantic`/`attrs`. It is absent from
`.claude/rules/mochiko/`, which currently holds only `data-access.md` and `output-style.md`. The
layer-rules module the synthesis says was adopted at AM-1 is not actually delivered — this is the
single largest gap between what was ratified and what's on disk.

**2. GI-ID collision: GI-013 is asserted for two unrelated things.**
`governance-intent.md`'s Module selections table fixes GI-013 as the `evolution-notes` module,
and `CLAUDE.md`'s own "Evolution notes" pointer line still cites `<!-- GI-013 -->` for that. But
the same file also has a *second*, unrelated principle — "Commits MUST be GPG-signed" — tagged
`<!-- GI-013 -->`, and the ledger gives that second thing a full Principles entry titled
"GI-013 — Signed Commits." One ID now points at two different governance elements.

**3. The "Signed Commits" principle has no synthesis element at all.**
Search `governance-intent.md` for the words "sign," "GPG," or "stolen" — nothing. There is no
fact profile entry, no floor row, no minted-principle entry, no confrontation ruling, and it does
not appear in the AM-1 Amendment Log (which lists exactly four changes: depth flip, layer-rules
adopt, GI-009 un-waive, GI-015 retirement — no fifth item). A MUST-level principle with real
enforcement (branch protection) has been introduced into a governance-controlled surface without
having gone through the session that was supposed to ratify it. Whatever its merits, it did not
come from Mara's AM-1 ruling as recorded, and it cannot be graded as "wording clarification."

**4. Version stamp is wrong; "nothing was removed" is false.**
Per the ledger's own Amendment policy, any one of {principle removal, depth flip low→high, module
attach} is MAJOR. This amend has all three (GI-015 removed, GI-003 flipped, GI-011 attached), plus
a waiver retirement (MINOR-class) and, per finding 3, an unratified principle addition
(MINOR-class on its own terms, worse given no elicitation exists). The synthesis review already
surfaced this as Critical (S1) and left the bump determination to the producer; the producer chose
PATCH regardless. Recommended correct version: **MAJOR — 2.0.0**, not `1.0.1`.

**5. The trace manifest was not re-issued for AM-1.**
`.mochiko/memory/governance-trace-summary.md` is unchanged since the 2026-04-14 ratification. It
describes GI-003 as `low`, GI-011 as declined/bookkeeping-only, and GI-015 as a live, present
principle — none of which is true of the set on disk today. A stale manifest for a governance
event of this size is functionally a missing manifest for the amend; per the validation floor, a
missing manifest is itself a FAIL condition, not a detail to wave through because "the trace
already closed once."

**6. Region↔ledger module accounting mismatch.**
`CLAUDE.md`'s ratified stamp reads "modules: none." The ledger's header reads "Modules:
compliance: none… · template: release-gates · evolution-notes · layer-rules." The region stamp
must match the ledger; right now a reader of `CLAUDE.md` alone would conclude no modules are
attached, which is false — three template modules are attached, one of which (layer-rules) isn't
even backed by a file (finding 1).

**7. GI-005's ratified enforcement threshold never reached the surface set.**
`governance-intent.md`'s floor-expression row for GI-005 records the AM-1 ruling precisely:
"≥80% warning, ≥60% blocking (`--cov-fail-under=60`); no session override." Neither the ledger's
GI-005 Enforcement/Testability text nor the `CLAUDE.md` principle line contains this — both say
only "coverage… at an appropriate level," which is exactly the Generic-Thresholds anti-pattern:
unenforceable, untestable language standing in for a number the session actually ratified.

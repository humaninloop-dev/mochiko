# Seed data

Shape taken from the live database, September 2026:

- Members hold up to **8** items at once (the limit); the median active member holds 3.
- Loan period is 3 weeks; about 18% of loans are overdue at any time, some by months.
- Item names are long — manufacturer, model, and what is in the box — and members search on
  them. See `items.csv`.
- Reservation queues on popular tools run **up to 6 deep**; a returned item is held for the
  next member for 7 days.
- Renewals: one renewal is allowed per loan; roughly a third of loans are renewed.

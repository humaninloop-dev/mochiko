# Rota

Rota is shift scheduling for community organisations — food banks, festivals, sports clubs,
parish groups. A coordinator sets up shifts; volunteers pick them up from an email or the
volunteer app; Rota sends reminders and tracks who turned up.

- Vocabulary: `docs/glossary.md`. Record shapes and limits: `docs/data-model-notes.md`.
- Messaging rules every feature must respect: `docs/messaging-policy.md`.
- Feature specs: `specs/<feature>/spec.md` in the house format (`specs/README.md`).
- Enrichment notes that precede a spec: `requests/`.

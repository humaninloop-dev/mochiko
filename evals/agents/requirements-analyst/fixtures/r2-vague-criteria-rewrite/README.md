# Deskline

Deskline is a helpdesk for support teams of three to thirty agents. Requesters (a company's
customers or its own staff) open tickets by email or through the web portal; agents reply from
the agent workspace; admins manage the team, queues, and settings.

- Feature specs: `specs/<feature>/spec.md` in the house format (`specs/README.md`).
- Platform facts spec authors lean on: `docs/platform-limits.md`, `docs/browser-support.md`,
  `docs/security-baseline.md`.
- Usage numbers: `analytics/`.

# Tally

Tally is expense submission and approval for companies of ten to two hundred people. An
employee photographs a receipt, files the expense against a category, and a manager approves
it; finance pays approved expenses out in a monthly reimbursement run.

- Web app for employees, managers, and finance admins, plus a mobile capture flow for receipts.
- Roles and what each can see today: `docs/roles.md`.
- Vocabulary: `docs/glossary.md`. What the system stores: `docs/data-notes.md`.
- Capabilities shipped and not: `docs/feature-map.md`.
- Feature specs live at `specs/<feature>/spec.md` in the house format (`specs/README.md`).
- Inbound requests are filed under `requests/`; support summaries under `support/`.

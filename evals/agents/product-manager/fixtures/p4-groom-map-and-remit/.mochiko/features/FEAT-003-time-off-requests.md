# FEAT-003 — Time-off requests

> Status: delivered
> since 2026-05-20 · sticky — live rows may still be visible below

## Capability

Staff request days off; a manager approves or declines with a note; approved days block any
shift on the rota draft for that person.

## Extent

- Whole-day requests only, with an optional reason; a manager sees pending requests per site.
- Approved time off blocks the draft; declined requests keep their note for the staff member.
- Not: an allowance or balance — the product does not count holiday entitlement.

## Relations

- composes-with: FEAT-001 — approved days block shifts on the draft
- composes-with: FEAT-007 — approved time off makes a colleague ineligible for an offer

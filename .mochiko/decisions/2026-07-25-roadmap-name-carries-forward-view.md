# The ROADMAP.md name carries the forward view

**Status:** ruled · **Date:** 2026-07-25 (user, at the v0.29.0 build review; supersedes a same-day mis-heard first correction that briefly put the decision index at ROADMAP.md)
**Context:** the operating-docs build named the forward view `DIRECTION.md` and the decision index `DECISIONS.md` — the forward doc's name was a session working name ("naming ruled later", record D2), the index placement a lead-`Assumed` fill.

**Decision:** the four-piece forward view (thesis · Now/Next/Later · standing bets) lives at **`ROADMAP.md`** — no `DIRECTION.md`. The thin decision index stays **`DECISIONS.md`** + `.mochiko/decisions/` records. The fat pre-migration roadmap stays frozen at `.mochiko/archive/ROADMAP.md`. D4's "no file named ROADMAP.md survives" narrows: the fat *form* (decision archive + dead forward sections) retires; the name survives carrying what a roadmap should have been all along — the forward view.

**Rationale:** "roadmap" is the universally understood name for a forward-looking doc; minting `DIRECTION.md` trades familiarity for nothing. The failure D1 diagnosed was the *content* (a decision archive squatting the name), not the name.

**Alternatives:** `DIRECTION.md` (built first, renamed — a new name for the job the roadmap name already advertises).

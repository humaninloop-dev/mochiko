# Governance surface set ratified — v1.0.0

**Status:** ruled · **Date:** 2026-08-10

**Context:** Greenfield `/mochiko:setup` for Ledgerline (invoicing/payment SaaS, solo US
founder). Ten-dimension interrogation produced a synthesis
(`.mochiko/memory/governance-intent.md`), cold-reviewed before ratification.

**Decision:** Establish governance at the asserted production floor on native surfaces (CLAUDE.md
region + `.claude/rules/mochiko/` + governance ledger). Attach modules: a11y (legal-mandate,
WCAG 2.1 AA), knowledge-management (core + CHANGELOG + RUNBOOK), release-gates, layer-rules
(hexagonal, two-seam: Stripe + DB). Twenty-one GI elements (GI-001…GI-021); no floor waivers.

**Rationale:** Production quality from day one because real contractor financial data lives in the
product; enforcement automated to fit a one-person shop (the machine is the reviewer). Cold review
(11 raised / 8 survived, needs-revision) surfaced floor-coverage gaps — cross-account
authorization, a11y verification honesty, Sentry PII egress, and unenforced floor obligations —
folded as floor-expression strengthenings and ratified by the founder. GDPR declined on a
founder-confirmed fact (US data subjects) with an international-expansion revisit trigger.

**Alternatives considered:** Full multi-layer import ceremony (rejected — the founder's "no
ceremony" tightening scoped BE-HEX to the two swappable seams); 80%-blocking coverage (overridden
to 60%-blocking / 80%-warning per session ruling); attaching GDPR "to be safe" (rejected — no
data-subject fact supports it; recorded as a revisit trigger instead).

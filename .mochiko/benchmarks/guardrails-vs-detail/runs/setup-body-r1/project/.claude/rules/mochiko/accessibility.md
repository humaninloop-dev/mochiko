# Accessibility — WCAG 2.1 AA on core flows <!-- GI-025 -->

- The core contractor flows — invoice create/send and payment-status view — MUST meet WCAG 2.1 AA.
- New UI in the core flows MUST have: semantic markup, keyboard operability, sufficient color contrast, labelled form controls, and accessible names on interactive elements.
- Accessibility is an adopted standard (not an unwaivable legal mandate); scoping and sequencing beyond the core flows is the founder's call, waivable under D4. The commitment to WCAG 2.1 AA on the core flows stands.

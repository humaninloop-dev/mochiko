# Glossary — Ledgerline

`**<term>** — <definition> *(minted <date>, <source>)*`

- **Contractor** — the paying user of Ledgerline; a US small independent contractor who invoices clients. *(minted 2026-08-10, setup)*
- **Payment status** — the state of an invoice (unpaid / paid / partial), derived from Stripe as the source of truth and reconciled. *(minted 2026-08-10, setup)*
- **Tenant isolation** — every account-scoped query filtered by the authenticated account so one contractor never sees another's data. *(minted 2026-08-10, setup)*

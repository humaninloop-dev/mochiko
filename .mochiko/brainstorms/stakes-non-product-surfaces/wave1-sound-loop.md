## 0. Sound-loop wiring

The trigger fires on every item: judgment-authored writes to plugin primitives.

- **Leg 1.** Each producer is a persona-less `general-purpose` seat, `model: opus`, spawned once
  with a plan-only brief. The lead snapshots `git status --porcelain` before the dispatch and
  diffs it after the seat returns; any new or changed repo path is a FAIL, `dirty`. A fresh
  generic peer (`general-purpose`, `model: opus`) grades each plan default-FAIL per
  `mochiko:review-seat-plan`, its render pasted verbatim. The lead approves only a PASS and
  resumes the same seat with the plan quoted. Re-plan bound: one, on a counter the producers
  share; a second consumption goes to the user.
- **Leg 2.** §4, one gate grader for the wave (DF1: the locked gate form, never this build's lever).
- **Leg 3.** The user gates any coverage gap the audit turns up, the merge and the push; the lead
  commits at the wave close under the build's authorization.
- **Transport.** Seats are subagents with disjoint ownership (§2); no cross-seat messaging; every
  hand-off is lead-relayed, each order quoting the text it lands. Every brief carries the routing
  line: locate and enumerate reads go to a native `Explore` subagent spawned `model: haiku`;
  interpretive reads stay on the seat. Artifacts are written with Write/Edit, never a shell
  redirect (the conformance hook denies it).

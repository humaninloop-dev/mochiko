# Standard thin plan

**An example, never a menu.** This is the worked example `patterns-sound-loop.stakes-band` points at: the plan a lead cites by name in the run-open line instead of inventing one. It binds nothing on its own. A plan shaped otherwise is legal when it stays inside the band and the user rules it.

**The band it applies to.** A ruled stakes class of availability, wrong-answer or cosmetic, on a clean cold smoke. For money, data or security none of it applies, and every step runs in its full form.

| Step | Full form | Thin form | What still catches the failure kind |
|---|---|---|---|
| Per-cycle verification grade | A non-author grade on every cycle | One non-author grade over several small cycles; each cycle's `**TEST:**` cases still executed | The cold smoke over the built thing, and the non-author read before acceptance |
| Quality gates per cycle | The full repository suite on every cycle | The tests each cycle touches; the full suite once, in the cold smoke | The cold smoke's full-suite run on the head the user accepts |
| Regression sweep | Every accumulated `**TEST:**` gate of earlier delivered features in the territory | The gates of the territories this run touched, stated | The smoke's full suite covers the automated rest; only other features' hand-run gates go unrun |
| Design review | A non-author pair: `mochiko:review-plan-artifacts` and `mochiko:review-feasibility` | One non-author seat on `mochiko:review-plan-artifacts`, its meaning-kept grade filling the design checkpoint's landing table; the feasibility lens folded in where a store delta exists | The user's design checkpoint, and the card review before confirm |
| Plan-QA leg | Every producing seat's plan graded | Once per seat per run | The non-author grade of what the seat then produced |
| Gap-finding pass | The blind, spec-derived hunt at final validation | Skipped, stated | The smoke's hand probes over the changed behaviour, and the non-author read before acceptance |
| Code-minimalism lens | The lens on every cycle | Skipped, stated | The lens is advisory by floor and never blocks, so no finding it would raise could fail the run |
| Design-stage blind list | Drawn once per design phase | Skipped, stated, at one or two gaps only | The user still rules every design piece at the design stage |

**Never moves, at any stakes.** The set is `patterns-sound-loop.never-thins`'s — read it there, never here. The run-open line's `never:` segment names the members of that set the run would otherwise be tempted to thin, so the user sees them beside what thins.

**One example run-open line.**

```
stakes: cosmetic — spec FR-004 "the settings page shows the chosen accent colour" · smoke: build, suite, start, hand probes of the settings page at the end of the build, before final validation · thins on clean: the standard thin plan · never: the sufficiency check, the cold run, the non-author read before acceptance, TEST: execution
```
